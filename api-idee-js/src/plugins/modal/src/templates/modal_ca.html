API-IDEE

API CNIG és una eina que permet integrar de manera molt senzilla un visualitzador de mapes interactiu a qualsevol pàgina web i configurar-lo consumint fitxers WMC, serveis WMS, serveis WFS, fitxers KML, etc. A més, proveeix la capacitat d'afegir una gran quantitat d'eines i controls.
