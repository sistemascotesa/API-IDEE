# Datos sintéticos para ShareMap

Los GPX, KML/KMZ, GeoTIFF, MBTiles, PBF y GeoPackage se reutilizan de las fixtures de API-IDEE. El GeoJSON, el estilo MapLibre, el terreno plano heightmap y el triángulo 3D son ejemplos sintéticos de esta tarea. No contienen archivos ni geometrías aportados por el usuario. El contexto WMC referencia el servicio público del IGN.

Se empaquetan en el WAR bajo `/test-data/sharemap/`. Estas URL son locales al entorno donde se despliega el WAR: para compartir con otras personas deben estar disponibles desde ese entorno. Son muestras de carga/serialización; no representan cartografía de producción.
